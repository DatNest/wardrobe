Безопасное обновление каталога Wardrobe
=======================================
В этом архиве НЕТ wardrobe.json и папки images намеренно: чтобы при обновлении
нельзя было случайно стереть опубликованные данные.

1. В репозитории GitHub замени только файл index.html из этого архива.
   wardrobe.json НЕ заменяй, папку images НЕ трогай.
2. Сначала открой обновлённый сайт НА ТЕЛЕФОНЕ — там, где уже заполнен каталог.
   Не очищай историю/данные сайта. Страница объединит телефонные записи
   с уже опубликованными, а не заменит их пустым файлом.
3. Если на телефоне есть GitHub-токен с правом записи, новые данные
   отправятся автоматически. Если нет — укажи токен в шестерёнке.
4. Затем открой обновлённую страницу на ПК. Там подтянется объединённый
   каталог. Чтобы редактировать с ПК, добавь токен в его браузере.

Автоматически: примерно через 12 минут при открытой странице,
при возвращении на вкладку, после подключения к интернету,
а также вскоре после внесения правок.
Одновременно выполняется максимум одна синхронизация — без лавины запросов.
В настройках GitHub появилась кнопка «Скачать локальную резервную копию».
Сам сайт сохраняет исходную локальную копию браузера в IndexedDB при первом запуске.

ВАЖНО: если страница закрыта или телефон усыпил браузер, таймеры не работают.
Синхронизация продолжится при следующем открытии.
