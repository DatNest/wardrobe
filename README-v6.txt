WARDROBE · исправление синхронизации v6 — 18 ноября 2026

ВАЖНО: ничего не удаляй на телефоне. Сохрани скачанный JSON как резервную копию.

УСТАНОВКА
1. В GitHub замени ТОЛЬКО index.html на файл из этого архива.
2. Не заменяй wardrobe.json и не трогай папку images.
3. Открой на телефоне https://datnest.github.io/wardrobe/?v=6
4. Проверь, что персонажи остались. Нажми стрелку вверх и дождись явного подтверждения сохранения на GitHub.
5. После УСПЕШНОЙ отправки открой сайт на ПК с ?v=6 и проверь каталог.

ИСПРАВЛЕНО
• В версии v5 адрес репозитория составлялся с завершающим «/»: /repos/owner/repo/
  GitHub REST API может отвечать на него HTTP 404. Сейчас используется /repos/owner/repo.
• Автоматические сетевые ошибки не показывают постоянно всплывающий тост.
• Прежние защиты локальных данных, резервной копии, интервала 12 минут и
  предотвращения одновременных запросов сохранены.

ЕСЛИ ОШИБКА «БРАУЗЕР НЕ ПОЛУЧИЛ ОТВЕТ» ОСТАЁТСЯ
Открой на телефоне в том же браузере https://api.github.com/zen
Если ссылка не открывается — это блокировка/сетевое соединение (часто VPN),
которое один только HTML-файл не исправит. Попробуй отключить или сменить VPN.
Если ссылка открывается — в настройках нажми «Проверить подключение» и
посмотри полный текст ошибки. Не отправляй никому токен.

Не импортируй повторно резервную копию, пока текущий каталог виден на телефоне.
