# Wardrobe — безопасная синхронизация (обновление 18.11.2026)

## ВАЖНО: как обновить без потери телефонного каталога

**В архиве намеренно нет `wardrobe.json` и `images/`.** Это не ошибка.
Они содержат **твой** каталог и фотографии. Не заменяй их пустыми файлами из старых архивов.

1. Сохрани уже скачанную телефонную резервную копию JSON в надёжное место. Не удаляй данные браузера телефона.
2. В GitHub-репозитории сайта обнови `index.html`; при желании обнови `README.md` и `robots.txt`.
   Все три файла лежат в корне архива. Загрузи содержимое архива, а не саму папку архива.
3. Открой сайт **на телефоне**, где заполнен каталог. Убедись, что персонажи и вещи видны.
   Если не видны — шестерёнка → **Восстановить из JSON (объединить)** → выбери скачанный файл.
   Импорт сохраняет имеющиеся записи и добавляет копии из резервной копии.
4. В шестерёнке проверь **логин GitHub, репозиторий, токен** и нажми **Проверить подключение**.
   В строке проверки должны появиться репозиторий, ветка и путь к `wardrobe.json`.
   Это проверка **чтения**; для отправки данных токен должен иметь право **Contents → Read and write**.
5. Если проверка успешна, сохрани настройки и дождись загрузки телефона в GitHub (или нажми стрелку вверх).
   После успешной отправки открой обновлённый сайт на ПК. Там данные прочитаются из GitHub.
6. Если ПК по-прежнему пуст — в его шестерёнке проверь, что указан **тот же репозиторий**.
   В сообщении указаны реальные количества персонажей, полок, вещей и внешностей на GitHub.

## Что делать с ошибкой 404

- `404: GitHub не видит ... с этим токеном` — неверный логин/название репозитория или токен не имеет доступа к **выбранному репозиторию**. Сверь адрес `https://github.com/логин/репозиторий`.
- `404 при записи ...` — для токена обычно не хватает прав **Contents → Read and write**, он выдан для другого репозитория либо запись в выбранную ветку запрещена.
- `Файл wardrobe.json не найден` — репозиторий доступен, но JSON отсутствует. Сайт ищет файл в корне и `docs/`, в основной ветке и `gh-pages`, если она существует. Если это действительно новый пустой репозиторий, стрелка вверх предложит **создать файл из локального каталога**, только после подтверждения.
- Ошибка 404 НЕ означает, что каталог на телефоне пуст. **Сайт больше не стирает телефонные записи и не объявляет их синхронизированными при такой ошибке.**

Если у тебя уже есть только локальный файл, **не выбрасывай его и не перезаписывай пустым GitHub JSON**.
После исправления доступа импортируй его через кнопку «Восстановить из JSON».
Если файл `wardrobe.json` в репозитории на самом деле отсутствует, его можно создать из резервной копии через GitHub, но это делай только после проверки правильной ветки и папки; старый каталог там нельзя заменять вслепую.

## Как теперь работает

- Синхронизация **каждые 12 минут**, когда сайт открыт в активной вкладке, при возвращении на вкладку и через несколько секунд после местных изменений.
- Если страница закрыта, телефон и компьютер не могут делать периодические запросы. При новом открытии проверка возобновляется.
- На фоне читается только JSON с GitHub. Фотографии загружаются **только при сохранении новых**, а не каждые 12 минут.
- Запросы к серверу не отправляются одновременно. Обновления файлов используют SHA, чтобы избежать прямой перезаписи нового содержимого.
- Новые вещи/персонажи/полки/внешности объединяются, а при конфликтах изменений сохраняется дополнительная версия.
- Явное удаление синхронизируется через отметку удаления, но отсутствие вещи в старой или пустой копии не считается удалением.
- Перед первой синхронизацией исходный каталог сохраняется в локальную резервную копию IndexedDB. Последующие изменения также сохраняются в IndexedDB, чтобы справляться с объёмными каталогами с фотографиями.
- В настройках можно скачать **резервную копию с фотографиями**. Если некоторые фотографии недоступны для скачивания, сайт предупредит — такие `images/...` нужно сохранять в GitHub отдельно.
- Настройки и токен не включаются в JSON-копию. Токен остаётся в браузере, в котором был введён.

## Содержимое архива

- `index.html` — сайт со всеми изменениями (включая синхронизацию и восстановление)
- `README.md` — эта инструкция
- `robots.txt` — прежний запрет индексации

`wardrobe.json` и каталог `images/` **не входят** в архив обновления из соображений безопасности данных.
