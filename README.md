# Мой гардероб — болванка

> При обновлении уже работающего сайта не заменяй `wardrobe.json` пустой болванкой из установочного архива: в опубликованном файле находятся все персонажи, вещи и внешности. Для обновления синхронизации достаточно заменить `index.html`.

Пустой сайт-гардероб: персонажи, полки с образами и раздел «Внешности».
Редактируется прямо на сайте, сохраняет изменения в твой GitHub-репозиторий.

## Как поставить

1. Создай свой репозиторий на GitHub (например, `wardrobe`) и загрузи в него все файлы из этой папки.
2. Settings → Pages → Deploy from a branch → `main` / root. Через минуту-две сайт откроется по адресу
   `https://ТВОЙ_ЛОГИН.github.io/wardrobe/`.
3. Создай токен: GitHub → Settings → Developer settings → Fine-grained tokens. Выбери только этот репозиторий,
   права: Contents → Read and write.
4. Открой сайт, нажми шестерёнку («Настройки GitHub») и впиши логин, название репозитория и токен.
   Токен хранится только в твоём браузере.
5. Появятся кнопки добавления. Создай персонажа, потом полку, потом добавляй образы (картинка + описание).
6. После изменения сайт автоматически сохраняет данные в репозиторий через 2,5 секунды. Стрелка вверх позволяет сохранить сразу, стрелка вниз — принудительно подтянуть данные обратно.

## Синхронизация телефона и компьютера

GitHub теперь служит общей копией. После редактирования на устройстве с введённым токеном дождись сообщения «Синхронизировано». Другое устройство читает свежий `wardrobe.json` непосредственно из GitHub при открытии сайта, возвращении на вкладку и затем раз в две минуты — ждать публикацию GitHub Pages больше не требуется.

Если на втором устройстве горит жёлтая точка, там есть собственные несохранённые изменения, поэтому автоматическая загрузка не перезаписывает их. Нажми стрелку вверх, чтобы сохранить их, либо стрелку вниз и подтверди замену, если локальные изменения не нужны.

## Внешности из NESS Library

Записи с ключом `ness_…` публикуются расширением NESS Wardrobe и считаются копиями общей NESS Library. Сайт автоматически проверяет `wardrobe.json` при открытии, возвращении на вкладку и затем раз в две минуты. Поэтому новая внешность появляется без очистки памяти браузера.

Если на сайте есть несохранённые изменения, автоматическое обновление подтягивает только внешности NESS Library и не трогает локальные персонажи, полки и вещи. Перед сохранением сайт ещё раз читает GitHub и добавляет актуальные библиотечные внешности в отправляемый файл — локальная старая копия больше не может их затереть.

Библиотечные внешности на сайте доступны для просмотра и копирования, но редактируются в профиле «📚 Ness Library». Обычные внешности, созданные непосредственно на сайте, по-прежнему редактируются здесь.

Без токена сайт работает в режиме просмотра.

## Приватность

- GitHub Pages на бесплатном аккаунте работает только с публичными репозиториями. Сайт увидит любой, у кого есть ссылка.
- В `robots.txt` стоит запрет индексации, поисковики сайт не покажут, но ссылку лучше никому не отдавать.
- Никому не показывай токен.

## Подключение к SillyTavern

Расширение «Каталог образов»: Расширения → «Каталог образов» → «Добавить каталог», впиши адрес своего сайта
(или прямую ссылку на `wardrobe.json`).

## Файлы

- `index.html` — сам сайт
- `wardrobe.json` — данные (персонажи, полки, образы, внешности)
- `images/` — картинки
- `robots.txt` — запрет индексации
