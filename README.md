# Мой гардероб — болванка

Пустой сайт-гардероб: персонажи, полки с образами и раздел «Внешности».
Редактируется прямо на сайте, сохраняет изменения в твой GitHub-репозиторий.

## Как поставить

1. Создай свой репозиторий на GitHub (например, `wardrobe`) и загрузи в него все файлы из этой папки.
2. Settings → Pages → Deploy from a branch → `main` / root. Через минуту-две сайт откроется по адресу
   `https://ТВОЙ_ЛОГИН.github.io/wardrobe/`.
3. Создай токен: GitHub → Settings → Developer settings → Fine-grained tokens. Выбери только этот репозиторий,
   права: Contents → Read and write.
4. Открой сайт, нажми шестерёнку («Настройки GitHub») и впиши логин, название репозитория и токен.
   Токен хранится только в твоём браузере.
5. Появятся кнопки добавления. Создай персонажа, потом полку, потом добавляй образы (картинка + описание).
6. Кнопка со стрелкой вверх сохраняет всё в репозиторий, со стрелкой вниз подтягивает данные обратно.

Без токена сайт работает в режиме просмотра.

## Приватность

- GitHub Pages на бесплатном аккаунте работает только с публичными репозиториями. Сайт увидит любой, у кого есть ссылка.
- В `robots.txt` стоит запрет индексации, поисковики сайт не покажут, но ссылку лучше никому не отдавать.
- Никому не показывай токен.

## Подключение к SillyTavern

Расширение «Каталог образов»: Расширения → «Каталог образов» → «Добавить каталог», впиши адрес своего сайта
(или прямую ссылку на `wardrobe.json`).

## Файлы

- `index.html` — сам сайт
- `wardrobe.json` — данные (персонажи, полки, образы, внешности)
- `images/` — картинки
- `robots.txt` — запрет индексации
