# Wardrobe — пустой шаблон полноценного сайта

Это чистая копия сайта Wardrobe из `DatNest/wardrobe`: сохранены **оригинальные интерфейс, функции, оформление и интеграция с NESS Wardrobe / SP-Wardrobe**, но нет исходных персонажей, одежды или фотографий.

## Состав шаблона

- `index.html` — полноценный сайт со встроенными стилями и JavaScript из оригинального репозитория; **не заглушка**.
- `wardrobe.json` — пустой каталог того же формата, что использует сайт: `chars`, `cats`, `items`, `looks` и `_sync`.
- `images/.gitkeep` — пустая папка. Файлы изображений будут появляться здесь после публикации новых карточек через сайт.
- `robots.txt` — запрет индексации поисковиками (не обеспечивает конфиденциальности!).

## Как установить

1. Скачай ZIP этой ветки и распакуй.
2. Создай отдельный репозиторий GitHub для своего сайта (рекомендуется новый, **не** тот, в котором уже есть данные).
3. Загрузи содержимое папки в корень репозитория: `index.html`, `wardrobe.json`, `robots.txt` и папку `images`.
4. В GitHub → **Settings → Pages** настрой публикацию **Deploy from a branch → main → /(root)**.
5. Открой адрес опубликованного сайта. В шестерёнке укажи свой GitHub-логин, название репозитория и **fine-grained personal access token** с доступом `Contents: Read and write` **только к этому репозиторию**, если хочешь загружать фотографии и сохранять каталог в GitHub.
6. Подожди публикации GitHub Pages и создай своего первого персонажа.

Для связи с расширением SillyTavern открой **SP-Wardrobe → Настройки → Библиотека персонажей** и укажи URL **нового** сайта, имя своего GitHub-аккаунта и имя репозитория. В расширении авторизация нужна только для публикации; чтение публичного сайта работает без токена.

## Важные предостережения

- Не распаковывай шаблон поверх своего действующего репозитория с нарядами: пустой `wardrobe.json` заменит реальные данные.
- Если открыть сайт на уже использовавшемся адресе в том же браузере, браузер может восстановить прежние данные из `localStorage` или IndexedDB. Для чистого старта используй **отдельный репозиторий и новый адрес GitHub Pages**.
- **Внимание:** старый сайт Wardrobe продолжает хранить введённые настройки GitHub (в том числе токен) в локальном хранилище браузера. Используй узко ограниченный токен; сайт имеет доступ к данным, которым пользователь разрешил синхронизацию.
- GitHub Pages и публичный репозиторий делают размещённые фото и описания публичными. `robots.txt` не скрывает эти файлы от прямого доступа.
- Оригинальные пользовательские картинки, данные и история синхронизации **не входят** в этот шаблон.

## Формат каталога

```json
{
  "chars": [],
  "cats": [],
  "items": [],
  "looks": [],
  "_sync": { "version": 4, "deleted": {} }
}
```

`chars` — персонажи, `cats` — полки, `items` — наряды/вещи, `looks` — внешности. Фотографии записей сохраняются в `images/` и связываются с записями через их `img`.

Этот шаблон подготовлен **только для установки в новый репозиторий**. Оригинальный `DatNest/wardrobe` в `main` не менялся.
