Wardrobe · исправление 403 и диагностики GitHub · v7, 18.11.2026

ОБЯЗАТЕЛЬНО СОХРАНИ РЕЗЕРВНУЮ КОПИЮ JSON С ТЕЛЕФОНА.
В архиве НЕТ wardrobe.json и НЕТ папки images: существующие данные не заменяются.

Установка:
1. Заменить ТОЛЬКО index.html на GitHub в репозитории DatNest/wardrobe.
2. Не удалять и не заменять wardrobe.json, images и данные браузера телефона.
3. На телефоне открыть https://datnest.github.io/wardrobe/?v=7
4. В настройках проверить владелец DatNest, репозиторий wardrobe и сохранённый токен.
5. Нажать «Проверить подключение», прочитать диагностическую строку.
6. ТОЛЬКО когда всё правильно, нажать стрелку вверх на телефоне.
7. После подтверждения «Каталог сохранён на GitHub» открыть на ПК ?v=7.

Исправления:
- Если в настройках задан токен, чтение GitHub API теперь тоже использует его.
  Раньше публичный репозиторий читался анонимно, что могло приводить к 403 при
  исчерпании лимита 60 запросов/час на публичный IP.
- Ошибка 403 теперь показывает текст ответа GitHub и число оставшихся запросов,
  различая rate limit и настоящие проблемы доступа.
- Проверка подключения явно подтверждает чтение с токеном.
- Сохранены объединение данных, локальное хранилище и синхронизация каждые 12 минут.

Если 403 останется: отправь текст диагностики БЕЗ токена.
Не перевыпускай токен без причины. Сохранённый JSON не удаляй.
